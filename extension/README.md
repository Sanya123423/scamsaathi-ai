# ScamSaathi Chrome Extension (Manifest V3)

Real-Time AI-Based Cyber Threat & Phishing Detection Browser Extension.

## How to Install in Google Chrome:

1. Open Google Chrome and navigate to:
   `chrome://extensions/`
2. Turn on the **Developer mode** toggle in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select this `extension` directory:
   `c:\Users\ASUS\Downloads\main scam sathi\extension`
5. The **ScamSaathi** shield icon will appear in your Chrome toolbar!

## Features:
- **Instant Page URL Inspection**: 1-click zero-request static URL phishing detection.
- **Message & SMS Analyzer**: Paste suspicious text/offers to detect OTP theft and coercion.
- **Right-Click Context Menu**: Highlight any text on any webpage -> Right-click -> "🛡️ Inspect with ScamSaathi".
- **Local Fallback Protection**: Heuristics continue protecting even if offline.
